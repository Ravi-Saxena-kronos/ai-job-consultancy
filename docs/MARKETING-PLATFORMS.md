## Regenerate ad PNGs

```bash
cd ai-job-consultancy
.venv/bin/python scripts/export_instagram_slides.py \
  --html public/job-seeker-ad-slides.html \
  --out public/job-seeker-ad-carousel
```

Optional JPEG: add `--jpeg` (requires `pip install Pillow`).

---

## Tips

1. Post the same **7 images in order** (01 → 07).
2. Always paste **https://ai-job-consultancy.vercel.app/** in the first or last line.
3. Do not spam groups; 1 promo per group per week max.
4. Keep disclaimer: we improve visibility; employers decide hiring.
